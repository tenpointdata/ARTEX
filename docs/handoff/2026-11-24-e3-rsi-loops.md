## Model drafter (`c-0aaa24`, 2026-11-24)

`propose.Drafter` (`rsi/propose/drafter.go`; `Input.Drafter`, nil = the fixed appended guidance) rewrites
the body of a rule that already qualified. Order in `Build`: transfer filter → fixed-body
`rsi.ValidateEdit` → rank by support → for each slot, draft. So only a role inside the search space
reaches the model, the model is called at most once per slot, and a refused body frees its slot for
the next rule. The `DraftRequest` holds only code-owned text (rule why/gate/guidance), the active body
and counts: no task id, lesson cue or finding text. A reply is refused, never repaired, when it adds,
drops or alters a `{{…}}` action, carries a stray delimiter, is empty or unchanged, matches a prior
body, or fails `rsi.ValidateEdit` (tail markers incl. `ARTEX_DATA`, role, size); `WriteArm` checks it
again. A drafted rationale carries `[drafted rule <id>]`, and the pruner skips a rule whose tag is in a
prior proposal for that role (`Prior.Rationale`), since a rewrite need not contain the guidance text.
`CheckDrafter` refuses a drafter whose model equals the judge (case and `provider/` prefix folded) or
when no judge is named; `run` checks it before any request. Arms carry `drafted_by`.

CLI: `--draft-model M [--draft-provider openai|anthropic|… --draft-url URL] --judge-model J` (default
`$JUDGE_MODEL`), key in `$ARTEX_DRAFT_API_KEY`. The adapter (`cmd/artex-rsi-propose/drafter.go`) uses
`agent.ConfigFrom` + `agent.Complete` (new: a tool-less single-turn completion, `agent/oneshot.go`) and
hands the active body inside `agent.FrameData` (new exported wrapper of the nonce data envelope).

Verified: `rsi/propose/drafter_test.go` (every tail marker plain/upper/zero-width split, a forged
envelope, new/dropped/stray template actions, over-cap, unchanged and empty outputs never become a draft
or an arm; immutable targets never reach the drafter; hostile task ids never reach it; drafter = judge
or unknown judge → no call), CLI test with a scripted model through the fake server. Mutation-checked:
removing either `checkDrafted` or the drafted-body `ValidateEdit` fails the test. Not checked: a real
model's drafts against a real instance and a held-out suite run (`c-4bbf29`).
